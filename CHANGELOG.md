## [1.0.0] - 2024-03-30

### Added | تمت الإضافة
- ✨ Initial release of Detailed General Ledger Report
- ✨ الإصدار الأول من تقرير دفتر الأستاذ المفصل
- 📊 Line-by-line display of GL Entries
- 📊 عرض سطر بسطر لقيود GL Entry
- 🎨 Color-coded display (Green for Debit, Blue for Credit, Red for negative balances)
- 🎨 عرض ملون (أخضر للمدين، أزرق للدائن، أحمر للأرصدة السالبة)
- 🔍 Comprehensive filters including all standard fields
- 🔍 فلاتر شاملة تتضمن جميع الحقول القياسية
- 🔄 Automatic detection and inclusion of Custom Fields
- 🔄 الكشف التلقائي وإضافة الحقول المخصصة
- 📐 Full support for Accounting Dimensions
- 📐 دعم كامل للأبعاد المحاسبية
- 💰 Running balance calculation
- 💰 حساب الرصيد التراكمي
- 📱 Support for multiple voucher types including Vouchers Entry
- 📱 دعم أنواع متعددة من السندات بما فيها Vouchers Entry

### Features | الميزات
- Works with Journal Entry, Sales Invoice, Purchase Invoice, Payment Entry, Vouchers Entry, Stock Entry, and more
- يعمل مع القيود اليومية، فواتير المبيعات، فواتير المشتريات، سندات الدفع، السندات المخصصة، قيود المخزون، وأكثر
- Compatible with Frappe Cloud
- متوافق مع Frappe Cloud
- Easy installation via bench or GitHub
- تنصيب سهل عبر bench أو GitHub
- Bilingual documentation (Arabic & English)
- توثيق ثنائي اللغة (عربي وإنجليزي)
